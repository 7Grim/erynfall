The old manifest over-claimed that a very large doc set was uniformly canonical and current.
That is not true anymore.

Some older docs remain useful reference material, but they must be cross-checked against:
- current code
- current architecture docs
- current art pipeline docs

Treat this file as a historical note, not an onboarding document.
